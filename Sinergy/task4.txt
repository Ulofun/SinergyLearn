### Анализ существующих решений Web-приложений на рынке ПО

Информационные системы, основанные на веб-технологиях, занимают доминирующее положение среди современных корпоративных приложений благодаря своей доступности, простоте развертывания и масштабируемости. Современные архитектуры Web-приложений включают следующие технологии и подходы:

#### 1. Клиент-серверная архитектура (Model-View-Controller / MVC)
Это наиболее распространённая архитектурная схема разработки Web-приложений. Она обеспечивает разделение бизнес-логики приложения (Model), интерфейса взаимодействия с пользователем (View) и управления приложением (Controller). Эта архитектура широко применяется практически всеми современными фреймворками (Laravel, Django, Ruby on Rails, ASP.NET Core).

#### 2. RESTful API и микросервисная архитектура
Современная тенденция заключается в создании отдельных сервисов, каждый из которых решает определённую задачу. Микросервисы взаимодействуют друг с другом посредством API-интерфейсов, используя протокол HTTP/S и форматы JSON/XML. Это позволяет быстро развивать отдельные компоненты приложения независимо друг от друга, повышая отказоустойчивость и производительность.

#### 3. Single Page Applications (SPA)
Web-приложения, использующие SPA-подход, загружают HTML-разметку единожды, после чего весь дальнейший контент подгружается динамически JavaScript-кодом. Популярные фреймворки React.js, Vue.js и Angular активно используют данную архитектуру, обеспечивая высокопроизводительные и удобные интерфейсы.

#### 4. Mobile First Design
Современные web-приложения разрабатываются с учётом мобильных устройств. Важно учитывать адаптивный дизайн, позволяющий удобно отображать сайт как на больших экранах компьютеров, так и на смартфонах.

#### Примеры популярных инструментов и платформ:
- **ASP.NET Core** (Microsoft) — платформа для разработки серверных приложений, позволяющая создавать полноценные современные веб-сервисы и веб-сайты.
- **PHP/Laravel** — популярный фреймворк PHP для быстрого создания мощных веб-приложений с поддержкой RESTful API.
- **Node.js** — среда исполнения JavaScript, поддерживающая создание серверных приложений и популярную архитектуру клиент-серверных приложений.
- **Django** (Python) — мощный инструмент для быстрой разработки сложных приложений, обеспечивающий высокий уровень безопасности и производительности.

### Возможности использования Web-приложений в компании

Использование технологий Web-приложений позволяет решить ряд важных задач корпоративного уровня:

1. **Централизованное управление данными:** доступ сотрудников к единой базе данных через браузер, возможность анализа и обработки данных централизованно.
2. **Безопасность и авторизация пользователей:** современные механизмы аутентификации и шифрования обеспечивают защиту конфиденциальных данных компании.
3. **Масштабируемость и доступность:** пользователи получают доступ к ресурсам и данным компании независимо от местоположения и устройства.
4. **Интеграция с существующими системами ERP/CMS:** интеграция корпоративных информационных систем позволяет повысить эффективность процессов компании и обеспечить единый источник данных.
5. **Простота поддержки и обновления:** изменения и улучшения легко распространяются через обновление сервера без необходимости устанавливать новые версии на стороне клиента.

### Практическое задание: Создание простого Web-приложения с использованием Delphi 10.2 и IIS

Создание Web-приложения на платформе Delphi подразумевает использование встроенного инструментария VCL WebBroker и связывание с базой данных Microsoft SQL Server.

#### Требования к проекту:
- Простое Web-приложение для регистрации посетителей мероприятия.
- Интерфейс формы для ввода имени посетителя, электронной почты и телефонного номера.
- Данные сохраняются в базе данных SQL Server.
- Серверное приложение размещено на IIS.

#### Основные этапы проекта:

##### 1. Установка и настройка окружения:
- Установлен Delphi 10.2 Tokyo.
- Установлена версия Microsoft SQL Server.
- Запущен и настроен MS Internet Information Server (IIS).

##### 2. Создание базы данных:
Создаём простую базу данных в SQL Server Management Studio с названием `EventRegistrationDB` и следующей структурой:

```sql
CREATE TABLE Visitors (
    VisitorID INT IDENTITY(1,1) PRIMARY KEY,
    Name NVARCHAR(100),
    Email NVARCHAR(100),
    PhoneNumber NVARCHAR(20)
);
```

Эта база данных должна содержать таблицу `Visitors`, хранящую информацию о зарегистрированных посетителях.

##### 3. Разработка Web-приложения в Delphi:
Используя модуль DataSnap Web Broker в Delphi, создаем простое приложение с формой для ввода данных и обработкой запросов через CGI/IIS.

Основные компоненты формы:
- EditBox для имени, email и телефона.
- Button для отправки данных.
- Компонент ADOConnection для подключения к SQL Server.
- Query компонент для вставки данных в таблицу.

Обработчик кнопки сохранения данных:

```delphi
procedure TForm1.Button1Click(Sender: TObject);
begin
  // Подключаемся к БД
  ADOConnection1.Connected := True;

  // Готовим запрос на вставку
  with ADOQuery1 do begin
    Close;
    SQL.Clear;
    SQL.Add('INSERT INTO Visitors(Name, Email, PhoneNumber)');
    SQL.Add('VALUES (:NameParam, :EmailParam, :PhoneParam)');
    Parameters.ParamByName('NameParam').Value := Edit1.Text;
    Parameters.ParamName('EmailParam').Value := Edit2.Text;
    Parameters.ParamByName('PhoneParam').Value := Edit3.Text;
    ExecSQL;
  end;

  ShowMessage('Данные успешно сохранены!');
end;
```

##### 4. Настройка публикации приложения в IIS:
Создаем виртуальный каталог в IIS, назначаем права на выполнение CGI-приложений и публикуем наше приложение.

#### Использование разработанного приложения:
Разработанное приложение доступно сотрудникам организации через внутренний портал. Пользователи могут регистрироваться на мероприятие, заполняя форму на сайте. Администратор видит полный список зарегистрированных участников в панели администрирования, интегрированной с базой данных.
